# Dank Lookup v0.5.0b: copy action fix

## Problem

`Qt.application.clipboard` is not available in the Quickshell/DMS runtime.
Clicking the pill Copy button produced:

```
DankLookup.qml[111]: TypeError: Value is undefined
```

The button refactor (v0.5.0a) was unaffected — the issue was the underlying
clipboard API, not the button component.

## Fix

Replace `Qt.application.clipboard.text = resultBody` with the same `Process`
pattern already used by `openFullSource()`:

```qml
function copyToClipboard() {
    if (!resultBody)
        return
    var p = Qt.createQmlObject(
        'import Quickshell.Io; Process { command: ["wl-copy"]; running: true }',
        root
    )
    if (p)
        Qt.callLater(function() { p.write(resultBody) })
}
```

`wl-copy` reads from stdin by default. Calling `p.write(resultBody)` feeds
the definition text to its stdin, which `wl-copy` then places into the Wayland
clipboard and primary selection.

- Clicking `C` pill button copies the definition text to clipboard.
- Pasting (Ctrl+V) in any application shows the definition text.
