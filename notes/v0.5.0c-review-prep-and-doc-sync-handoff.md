# Dank Lookup v0.5.0c: review prep and doc sync handoff

This handoff is for review preparation only. Do not add new UI features, new
dictionary sources, routing behavior, or backend behavior in this step.

The goal is to make the current local implementation easier to review by
aligning docs with the actual code and collecting a small set of positive
verification evidence.

## Current state

The local implementation has moved past the original v0.5.0a handoff in two
important ways:

1. `DankIconButton.qml` and `DankPillActionButton.qml` were attempted as helper
   components, but the current working implementation uses inline `T.Button`
   blocks in `DankLookup.qml`.
2. `copyToClipboard()` no longer uses `Qt.application.clipboard`; it uses
   `Quickshell.Io.Process` with `wl-copy`.

Before code review, the documentation should describe this actual state rather
than the earlier intended state.

## Task 1: sync stale roadmap text

In `github-release-roadmap.md`, the v0.4.6 section still describes the copy
action as:

```text
Copy action copies resultBody to clipboard (Qt.application.clipboard, no shell dependency)
```

Replace it with wording that matches the current implementation:

```text
Copy action copies resultBody to clipboard through Quickshell.Io.Process + wl-copy
```

If the roadmap has another place mentioning `Qt.application.clipboard`, update
that too. Do not change unrelated roadmap sections.

## Task 2: add v0.5.0a implementation note

Append a short implementation note to
`v0.5.0a-qml-button-refactor-handoff.md`.

Required content:

- External helper components were planned and attempted.
- Current working implementation uses inline `T.Button` blocks in
  `DankLookup.qml`.
- Direct `cursorShape` on `T.Button` was not compatible in this Quickshell
  runtime.
- Cursor behavior is implemented by an embedded `MouseArea` with
  `acceptedButtons: Qt.NoButton`.
- This is a pointer-cursor shim, not a return to the old clickable
  `Rectangle + MouseArea` control pattern.

Suggested heading:

```md
## Implementation note after local test
```
