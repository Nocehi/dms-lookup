# Dank Lookup v0.4.6: pill + utility actions

## Changes in DankLookup.qml

### 1. New functions (after `activeSourceLabel`)

```qml
function copyToClipboard() {
    if (resultBody)
        Qt.application.clipboard.text = resultBody
}

function openFullSource() {
    if (!resultBody)
        return
    var p = Qt.createQmlObject(
        'import Quickshell.Io; Process { command: ["sh", "-c", "cat > /tmp/dank-lookup/full.txt && xdg-open /tmp/dank-lookup/full.txt"]; running: true }',
        root
    )
    if (p)
        Qt.callLater(function() { p.write(resultBody) })
}
```

### 2. Single-mode pill row (before `segmentedRow`)

Visible when `availableModes.length === 1`. Shows mode label pill + C (Copy)
button + F (Open full) button.

### 3. Segmented row visibility

Added `&& root.availableModes.length > 1` to the existing visibility
condition, so the full segmented row is hidden when only one mode is available.

## Acceptance

| Query | Result |
|-------|--------|
| `俳句` / `日本語` | single pill `[日語]` + C + F |
| `字典` / `合格` / `春` | segmented row `[漢語] [粵語] [日語]` |
| `consolidate` / `adherence` | single pill `[英英]` + C + F |
| Click C | definition copied to clipboard |
| Click F | `xdg-open /tmp/dank-lookup/full.txt` |
